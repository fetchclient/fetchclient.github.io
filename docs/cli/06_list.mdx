The `list` command displays collections, folders, and variables stored in the Fetch Client data directory.

It helps you discover available resources before executing other commands such as `run`.

The `list` command supports filtering by **id** or **name**, making it easy to locate specific resources.

## 💻 Syntax

```bash
fc-cli list [options]
```

### ⚙️ Options

| Option          | Description             |
| --------------- | ----------------------- |
| `--col`         | List collections        |
| `--fol`         | List folders            |
| `--var`         | List Variable Sets      |
| `--name <name>` | Filter by resource name |
| `--id <uuid>`   | Filter by resource ID   |

## 📖 List Commands

| Command                           | Description                                        |
| --------------------------------- | -------------------------------------------------- |
| `fc-cli list --col`               | List all collections.                              |
| `fc-cli list --col --id <uuid>`   | Display the collection with the specified ID.      |
| `fc-cli list --col --name <name>` | Display collections matching the specified name.   |
| `fc-cli list --fol`               | List all folders.                                  |
| `fc-cli list --fol --id <uuid>`   | Display the folder with the specified ID.          |
| `fc-cli list --fol --name <name>` | Display folders matching the specified name.       |
| `fc-cli list --var`               | List all variable sets.                            |
| `fc-cli list --var --id <uuid>`   | Display the variable set with the specified ID.    |
| `fc-cli list --var --name <name>` | Display variable sets matching the specified name. |
