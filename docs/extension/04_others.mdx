## 🤝 How to Contribute

We welcome your contributions! Follow these steps to help improve Fetch Client:

1. **Search for existing issues** - Check the [Issues page](https://github.com/Ganesan-Chandran/vscode-fetch-client/issues) to see if someone is already working on your idea
2. **Create a fork** - Fork the repository and create a new branch for your changes
3. **Write clear messages** - Use simple, descriptive commit messages that explain what you changed
4. **Test your work** - Make sure your changes work correctly and don't break existing features
5. **Open a pull request** - Describe your changes clearly when you submit your pull request

Need help or have an idea? Use these links:
