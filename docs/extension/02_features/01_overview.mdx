# Overview

Fetch Client is a complete REST API testing tool built into VS Code. It helps you test, debug, and document your APIs without leaving your editor.

## 🎯 What You Can Do

### Make HTTP Requests

Send requests using any standard method:

- **GET** - Get data from a server
- **POST** - Send new data to a server
- **PUT** - Update existing data completely
- **PATCH** - Update part of existing data
- **DELETE** - Remove data from a server
- **HEAD** - Check if data exists (without downloading it)
- **OPTIONS** - See what methods are allowed

### Authenticate Your Requests

Connect to protected APIs using these authentication methods:

- **Basic Auth** - Simple username and password
- **Bearer Token** - Token-based security (like JWT)
- **API Key** - Secret keys sent in headers or URL
- **AWS Signature** - Amazon Web Services authentication
- **OAuth 2.0** - Modern authorization standard

### Send Different Types of Data

Choose the format that matches your API needs:

- **Form Data** - Upload files and form fields
- **Form-Encoded** - Standard web form submissions
- **Raw Data** - Send JSON, XML, or plain text
- **Binary Files** - Upload images, documents, and other files
- **GraphQL** - Query and mutate GraphQL APIs

### View Response Data

See your API responses in multiple ways:

- **Tree View** - Browse JSON and XML as an expandable tree
- **Raw View** - See the original response with color coding
- **HTML Preview** - View HTML responses as rendered web pages
- **Headers** - Check all response headers
- **Performance** - See response time and data size

### Test Your APIs

Verify that your APIs work correctly:

- Check if the status code is correct (200, 404, etc.)
- Validate response body content
- Test response times
- Verify headers are present
- Check specific JSON properties and values

### Organize with Collections

Keep your work organized and shareable:

- Group related requests into collections
- Import and export collections as JSON files
- Run all requests in a collection with one click
- Share collections with your team through version control
- Compatible with Postman and Thunder Client imports

### Use Variables and Environments

Avoid repeating yourself with variables:

- **Global Variables** - Use the same values across all requests
- **Collection Variables** - Share values within a collection
- **Request Variables** - Set values for a single request
- **Environment Switching** - Easily switch between dev, staging, and production

### Developer-Friendly Tools

Work faster with built-in utilities:

- **Code Snippets** - Generate code in 9+ programming languages
- **cURL Import** - Convert cURL commands to requests
- **Request Logs** - View history of all sent requests
- **Cookie Management** - Save and reuse cookies automatically
- **Auto-Request** - Automatically trigger requests when files change

## ⭐ Why Use Fetch Client?

✅ **Works Offline** - All features available without internet (except sending requests)  
✅ **Privacy First** - Your data stays on your computer  
✅ **Lightweight** - Fast and doesn't slow down VS Code  
✅ **Free Forever** - 100% open source with no limits  
✅ **Theme Support** - Matches your VS Code theme automatically
