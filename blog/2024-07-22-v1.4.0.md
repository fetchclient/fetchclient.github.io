We are happy to share version [**1.4.0**](https://github.com/Ganesan-Chandran/vscode-fetch-client/releases/tag/v1.4.0) 🎉.  
This update adds many helpful features for requests, testing, variables, and logs. It also fixes important issues.

<!-- truncate -->

## 🎉 New Features

- **Import Postman Collection v2.1** - You can now import Postman collections in v2.1 format.
- **OAuth2 support** - OAuth2 is now available for request authorization.
- **Pre-requests and conditions** - You can run pre-requests (Pre-Fetch) and use conditions before request execution.
- **Tests and Variables moved to PostFetch** - Tests and Variables are now in one clear place: PostFetch.
- **Type generation for JSON response** - You can generate types from JSON responses.
- **Auto refresh for request tabs** - Request tabs now refresh automatically when variables change.
- **Request and response logs in Output window** - Logs are now available for both request and response.
- **"View Log" button in sidebar** - A new button opens the log output window quickly.
- **Variable preview on hover** - You can see variable values when you hover over them.
- **Import .env files** - You can import .env files in the Variables section.
- **System variables for random data** - New system variables help you create random dynamic data.
- **Sidebar focus sync** - The matching sidebar item now stays focused when you change request tabs.
- **Show more in test output** - Large responses in test case output now have a show more option.
- **New test helpers** - Added `isJson()`, `regex`, and `notContains` options in tests.
- **Nested variables support** - You can now use variables inside other variables.
- **"New Request" shortcut icon** - Added in Collection and Folder for faster request creation.
- **Word wrap in response section** - Response text can now wrap for easier reading.

## 🐛 Bug Fixes

- **Import from cURL fixed** - Fixed import from cURL.
- **Collection tab opening issue fixed** - Clicking a collection item now switches to the existing tab instead of opening a new one every time.
- **Postman import/export fixes** - Fixed import/export for Postman collections and environments.

## Requirements

- **Minimum VS Code version:** 1.75.0
- **Minimum Node.js version:** 18.20.3

Thanks for using Fetch Client and sharing feedback. More updates are coming soon.
