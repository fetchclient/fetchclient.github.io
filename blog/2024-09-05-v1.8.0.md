We are happy to share version [**1.8.0**](https://github.com/Ganesan-Chandran/vscode-fetch-client/releases/tag/v1.8.0) 🎉. We are happy to share some new updates.

<!-- truncate -->

## 🎉 New Features

- **Auto Request (Request Scheduling)** - You can now schedule requests with the new Auto Request feature. This helps you run requests at the right time without doing it by hand.

- **New PreFetch Result Tab** - In the Response section, we added a new tab for PreFetch request results. Now it is easier to view and check PreFetch data.

- **Better Thunder Client Collection Import** - When you import a Thunder Client collection, it now includes:
  - Set variables
  - Tests

## Requirements

Please make sure your system meets these minimum versions:

- VS Code: v1.75.0 or later
- Node.js: 18.20.3 or later

More improvements are on the way.
