We are happy to share version [**1.6.0**](https://github.com/Ganesan-Chandran/vscode-fetch-client/releases/tag/v1.6.0) 🎉.  
This update adds useful request tools and improves collection settings. It also fixes important issues.

<!-- truncate -->

## 🎉 New Features

- **Direct run menu for requests** - Added a new menu to run requests directly.
- **Headers and pre-requests in collection settings** - You can now add headers and pre-requests at collection level.
- **Headers in folder settings** - You can now add headers at folder level.
- **Skip parent headers and pre-requests** - Added options in the request panel to skip parent headers and parent pre-requests.
- **Run parent pre-requests in Run All** - In Run All, parent pre-requests from collection or folder now run for all requests.
- **Import Thunder Client v1.2 data** - Added support to import Thunder Client collections (v1.2) and variables (v1.2).
- **Backup for storage location change** - Added backup support when changing location from global storage to workspace path.
- **Response code and time in logs by default** - Logs now include response status code and response time automatically.
- **Menu to open documentation** - Added a new menu to quickly go to Fetch Client documentation.

## 🐛 Bug Fixes

- **URL query parameter issue fixed** - Fixed a URL issue when the URL has query parameters.

## 🔗 Miscellaneous

- **Documentation improved** - Updated the Fetch Client documentation.

## Requirements

- **Minimum VS Code version:** 1.75.0
- **Minimum Node.js version:** 18.20.3

## Thank you

Thanks for using Fetch Client and sharing feedback. More updates are coming soon.
