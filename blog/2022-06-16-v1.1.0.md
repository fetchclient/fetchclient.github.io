We are happy to release Fetch Client [v1.1.0](https://github.com/Ganesan-Chandran/vscode-fetch-client/releases/tag/v1.1.0)🎉.

This update adds better collection tools, stronger auth support, and easier testing.

<!-- truncate -->

## 🎉 New Features

### Collection and Folder Updates

- You can now add folders inside a collection.
- You can copy and paste items between collections and folders.

### Environment Variable Improvements

- You can set environment variables from:
  - JSON response
  - headers
  - cookies
- Variables are now highlighted for better visibility.

### Authentication and Cookies

- AWS Signature auth type is now supported.
- Cookie support is improved.
- A new Manage Cookies feature is added.

### Better Testing Options

- New test case options are added:
  - Length
  - Type

### Smarter Request Behavior

- The `Content-Type` header is now added automatically based on request body type.
- You can press `Ctrl+S` to save a request.

### Better Sidebar and Menu Tools

- Right-click context menu is added in the sidebar for:
  - History
  - Collection
  - Variable
- New menu items are added:
  - Manage Cookies
  - View Error Log
  - Extension Settings

## 🐛 Bug Fixes

- Minor bug fixes and stability improvements.
