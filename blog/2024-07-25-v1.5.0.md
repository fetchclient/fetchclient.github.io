We are happy to share version [**1.5.0**](https://github.com/Ganesan-Chandran/vscode-fetch-client/releases/tag/v1.5.0) 🎉.  
This update makes workspace use easier and gives you better control over responses. It also fixes important issues.

<!-- truncate -->

## 🎉 New Features

- **Import Postman environment** - You can now import Postman environment files.
- **Save all request data in custom workspace** - All request data can now be saved in a custom workspace.
- **Configurable response limit** - You can now set the response limit based on your need.

## 🐛 Bug Fixes

- **Import from cURL fixed** - Fixed import from cURL.
- **POST method fix for new requests** - Fixed an issue where POST was not set correctly right after creating a new HTTP request in a collection.
- **Run All fixes** - Fixed bugs in the Run All section.
- **Sidebar filter search fixes** - Fixed bugs in filter search in the collection section of the sidebar.

## Requirements

- **Minimum VS Code version:** 1.75.0
- **Minimum Node.js version:** 18.20.3

## Thank you

Thanks for using Fetch Client and sharing feedback. More updates are coming soon.
