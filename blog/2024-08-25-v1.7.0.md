We are happy to share version [**1.7.0**](https://github.com/Ganesan-Chandran/vscode-fetch-client/releases/tag/v1.7.0) 🎉.

<!-- truncate -->

## 🎉 New Features

- **Encrypted environment variables** - Environment variables are now stored in encrypted format.
- **New encryption settings** - Added new settings for encrypted environments and encryption when exporting variables.
- **Bulk export** - You can now bulk export collections and variables.
- **Bulk import** - You can now bulk import collections and variables.
- **Hidden variables on screen** - Variable values are now hidden in the Variables screen for better safety.

## 🐛 Bug Fixes

- **Cookie name parsing fixed** - Fixed an issue where the cookie name was not parsed correctly.
- **Manage Cookie button added** - Added a **Manage Cookie** button in the cookie section of the Response panel.

## 🔗 Miscellaneous

- **New feedback menu options** - Added menu options to raise requests/issues and write a review for Fetch Client.
- **GitHub Action for release flow** - Added a GitHub Action to build the VSIX package and publish the extension.

## Requirements

- **Minimum VS Code version:** 1.75.0
- **Minimum Node.js version:** 18.20.3
