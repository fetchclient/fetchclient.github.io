We are happy to share version [1.2.0](https://github.com/Ganesan-Chandran/vscode-fetch-client/releases/tag/v1.2.0)🎉. This update adds useful tools for collections, auth, and requests. It also fixes an important token issue.

<!-- truncate -->

## 🎉 New Features

- **Nested folders in collections** - You can now create nested folders inside a collection. This helps you keep requests organized in a better way.

- **Run cURL requests from the sidebar** - You can now run cURL requests under a collection in the sidebar.

- **Import cURL requests from the sidebar** - You can also import cURL requests under a collection in the sidebar. This was added in issue #5.

- **Auth settings for collections and folders** - You can now set auth at both collection level and folder level. This gives you more control and saves setup time.

- **"Inherit auth from parent" option** - A new option, **Inherit auth from parent**, is now in the Auth section. This makes it easy to reuse auth settings from the parent item.

- **Reorder and disable requests in "Run All"** - In a collection, you can now reorder requests and disable selected requests in **Run All**.

- **File option in form body** - A new file option is added in **Form** under request body. Now you can upload files more easily.

- **Full screen response mode** - The response section now supports full screen mode, so it is easier to read large responses.

## 🐛 Bug Fixes

- **Bearer token variable issue fixed** - We fixed an issue where a Bearer token used as a variable did not work because of a max length limit.

## Thank you

Thanks for using the product and sharing feedback. More improvements are coming soon.
